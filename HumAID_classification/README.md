# HumAID Classification: Hurricane Maria Tweets

Este proyecto contiene un notebook de clasificación de tweets relacionados con el Huracán María, utilizando el dataset HumAID. El objetivo es identificar y categorizar información relevante publicada en Twitter durante el desastre, facilitando el análisis de necesidades humanitarias y la respuesta ante emergencias.

## Contenido

- **Preprocesamiento de datos:** Limpieza y preparación de los tweets para su análisis.
- **Exploración de datos:** Análisis descriptivo y visualización de la distribución de categorías y características del dataset.
- **Entrenamiento de modelos:** Implementación de modelos de machine learning para la clasificación automática de los tweets.
- **Evaluación de resultados:** Métricas de desempeño y análisis de los resultados obtenidos.
- **Conclusiones:** Discusión sobre el impacto y posibles mejoras del modelo.

## Requisitos

- Python 3.8+
- Bibliotecas principales: pandas, numpy, scikit-learn, matplotlib, seaborn, nltk, (y otras especificadas en requirements.txt).

## Uso

1. Clona este repositorio y navega a la carpeta HumAID_classification.
2. Instala los requisitos:
   ```
   pip install -r requirements.txt
   ```
3. Abre el notebook en Jupyter:
   ```
   jupyter notebook Classification_Model_Hurracane_Maria_tweets.ipynb
   ```
4. Ejecuta las celdas siguiendo el flujo del análisis.

## Dataset

El notebook utiliza el dataset HumAID, específicamente los tweets relacionados con el Huracán María. Asegúrate de contar con los archivos de datos necesarios en la ruta correspondiente (HumAID_maria_tweets).

## Resultados Esperados

- Clasificación automática de tweets en categorías humanitarias.
- Visualizaciones sobre la distribución y evolución de la información durante el desastre.
- Métricas de desempeño de los modelos implementados.

## Créditos

- Proyecto desarrollado en el marco del análisis de desastres naturales y respuesta humanitaria en Puerto Rico.
